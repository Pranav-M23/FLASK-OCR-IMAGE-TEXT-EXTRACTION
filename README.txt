Flask OCR Project Setup


System Requirements:

- Python 3.10.8 or lower for the working of PaddleOCR

Installation Instructions:

1. Install Python (if not already installed):
   - Make sure to use Python 3.10.8 or a lower version for compatibility.

2. Install necessary Python packages via pip:
   Open your command prompt or terminal and run:

pip install flask
pip install paddlepaddle
pip install paddleocr

Running the Application:

1.Open the source files in your code editor
  aadharocr.py – The main python  Flask application
  templates/aadhar2.html – The frontend HTML (inside the templates folder)
  static/style.css – The stylesheet (inside the static folder)

2.Run the Flask app:
 From your terminal, inside the project folder:
 Run
 python aadharocr.py

3.Click  the URL shown (http://127.0.0.1:5000/) into your browser to launch the project
